## 二、导入方法（三选一）

### 方法 1：本地文件导入（推荐，最稳定）

1. **把 json 文件传到手机**，任选一种：
   - 数据线连电脑 → 手机存储 → 随便放个目录（如 `内部存储/Download/`）；
   - 用微信/QQ 的「文件传输助手」发到手机，再"用其他应用打开/保存到手机"；
   - 放到网盘（夸克/百度），手机端下载到本地。
2. 打开手机上的 **FongMi** → 首页右上角 **设置**（齿轮图标）
3. 点 **点播** → 弹出对话框里有两个输入框：
   - 上面 `请输入名称…` → 可填 `我的字典`（可留空）
   - 下面 `请输入配置…` → **点输入框右侧那个小图标（选择文件）**
4. 在弹出的文件选择器里找到刚传进来的 json，选中
5. 点 **确定** → 回到首页，等待自动加载（会下载爬虫包，第一次大约 10～60 秒）

> 想换配置：再点一次「点播」，输入框里长按可编辑/清空，或直接选另一个文件。
> 电视/盒子版（leanback）界面相同，按钮叫「选择」。

### 方法 2：直接粘贴在线地址（不用传文件）

打开 `docs/在线接口地址.txt`，挑一条复制，粘贴到上面第 3 步的 `请输入配置…` 里，点确定即可。
推荐这几条（实测公网可达）：

```
①高天流云·聚合JS（298站点）
https://ghproxy.net/https://raw.githubusercontent.com/gaotianliuyun/gao/master/js.json

②老刘备（234站点）
https://ghproxy.net/https://raw.githubusercontent.com/liu673cn/box/main/m.json

⑤王二小（99站点）
https://9280.kstore.vip/aiwex.json

⑦clun（97站点 + 17路直播）
https://clun.top/box.json
```

### 方法 3：二维码免手输

手机自带相机 / 微信扫一扫 → 扫 `qrcode/` 里的图片 → 读出地址 → 复制粘贴到 FongMi 的配置框。

> 注意：FongMi 自带的扫码功能是用于**投屏/同步**的，不能直接扫配置，所以要用手机系统相机或微信扫。

## 五、常见问题

**Q：导入后首页空白 / 一直转圈？**
A：第一次加载要下载爬虫包（约 20～30 MB），耐心等；仍不行就换 `config/multi.json` 里的另一条线路。

**Q：某个站点点进去没反应？**
A：影视源时效性强，个别站点失效正常。在首页搜索影片，会同时搜所有站点，能出结果就能看。

**Q：加载提示 "Depot urls is empty" 或没反应？**
A：确认选的是 `.json` 文件而不是 `.txt`；确认文件完整（大小应与本目录一致）。

**Q：过一段时间接口失效了？**
A：运行 `python tools/update.py`（Windows 双击 `tools/update.bat`） 重新抓取生成，再把新文件传到手机。**这个脚本只生成文件，不会启动任何服务。**

**Q：为什么不直接给我一个网址？**
A：你的要求是"不用电脑当服务器"。公网接口地址随时可能失效，所以本字典以**本地文件**为主：文件在手机里，接口失效时用工具重新生成即可，全程不需要电脑常驻。

## 六、已知限制（如实说明）

- **约 15 个站点的爬虫包托管在第三方镜像**（`tv.nxog.top`、`rihou.vip`、`agit.ai`、`tvbox.cainisi.cf` 等），本机网络访问不到，手机运营商网络下**可能可用**。这些站点打不开不影响其他 1150+ 个站点。
- **tvyuan 全量线路（1356 站点）和饭太硬**在本机网络无法直连验证，已放进"备用线路"，手机上大概率能用。
- **二维码需要用手机系统相机或微信扫**（FongMi 自带的扫码只用于投屏/同步，不能导入配置）。
- **电子节目单（EPG）**：常用 EPG 源在部分网络下不通；不影响看电视直播。
- 上游线路普遍存在**失效站点**（我剔除的 74 个站点，是上游配置文件里指向的文件已不存在，在 App 里同样打不开）。
